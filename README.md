# سامانه جامع مدیریت گله دام سبک (گوسفند و بز) — «دام سبک مدیران»

نرم‌افزار کامل و حرفه‌ای مدیریت گله‌های گوسفند و بز با محیط کاربری کاملاً فارسی، تقویم شمسی (جلالی)، و محاسبات پیشرفته علوم دامی.

---

## 🚀 راهنمای سریع نصب و اجرا روی کامپیوتر (Desktop Setup)

برای نصب و اجرای برنامه روی هر کامپیوتر شخصی یا سرور بدون نیاز به پیکربندی پیچیده، مراحل زیر را دنبال کنید:

### ۱. پیش‌نیازها
* **پایتون (Python):** نسخه 3.11 یا بالاتر ([دانلود از وب‌سایت رسمی پایتون](https://www.python.org/downloads/))

### ۲. نصب محیط مجازی و وابستگی‌ها
ترمینال (Command Prompt / PowerShell / Terminal) را در پوشه پروژه باز کرده و دستورات زیر را اجرا کنید:

```bash
# ایجاد محیط مجازی (Virtual Environment)
python -m venv venv

# فعال‌سازی محیط مجازی در ویندوز:
venv\Scripts\activate

# فعال‌سازی محیط مجازی در لینوکس / مک:
source venv/bin/activate

# نصب تمام وابستگی‌های نرم‌افزار
pip install -r requirements.txt
```

### ۳. اجرای برنامه با یک دستور
دستور زیر را در ترمینال اجرا کنید:

```bash
python run.py
```

* **داده‌های دمو به صورت خودکار:** در اولین اجرا، پایگاه‌داده SQLite به صورت خودکار ایجاد شده و ۴۰ دام، بهاربندها، اسپرم‌ها، داروها و سوابق دمو بارگذاری می‌شوند.
* **دسترسی مرورگر:** مروگر اینترنت خود (Chrome, Edge, Firefox) را باز کرده و به آدرس زیر بروید:
  `http://127.0.0.1:5000`

## 📋 امکانات و ماژول‌های نرم‌افزار

۱. **مدیریت شناسنامه و پرونده دام‌ها:** ثبت پلاک پلاستیکی، سریال، شناسنامه ملی، گوش فلزی، نژاد، گونه، جنسیت و بهاربند.
۲. **شجره‌نامه و محاسبات ژنتیک:** نمایش درخت شجره تصویری، محاسبه خلوص خونی و ضریب همخونی Wright ($F$) برای جلوگیری از همخونی ناخواسته.
۳. **تولیدمثل و تلقیح:** ثبت تلقیح مصنوعی/طبیعی، سیدرگذاری، ثبت فحلی بدون تلقیح، خشکی، و زایش به همراه زنجیره خودکار ثبت بره/بزغاله تازه متولد شده.
۴. **پزشکی و دامپزشکی:** ویزیت‌ها و درمان‌ها، ثبت مصرف دارو بدون ویزیت، و واکسیناسیون به همراه تاریخ ثبت و گزارش کامل.
۵. **رکوردگیری و استانداردسازی شیر:** محاسبه میانگین روزانه شیر، برآورد تولید کل بر اساس روش فاصله آزمون (ICAR TIM)، و محاسبه شیر تعدیل‌شده با ۴٪ چربی ($FCM_{4\%}$) طبق فرمول Gaines به همراه نمودار Chart.js.
۶. **عملیات جمعی (Bulk Operations):** فیلتر و تشکیل لیست کاری، اعمال سریع عملیات یکسان (واکسن، سیدر، حذف)، و بچ تراکنش‌های دسته‌جمعی با قابلیت رول‌بک کامل.
۷. **چاپ و گزارش‌گیری:** چاپ مستقیم شناسنامه دام و گزارش‌های زایش، تلقیح، شیر و خروج با طراحی اختصاصی `@media print` و خروجی اکسل (`.xlsx`).
