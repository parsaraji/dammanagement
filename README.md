# راهنمای سامانه مدیریت دام سبک (گوسفند و بز - "دام سبک مدیران")

این برنامه یک سامانه کامل تحت وب به زبان پایتون (Flask) جهت مدیریت گله‌های گوسفند و بز می‌باشد که تمامی بخش‌های آن کاملاً فارسی، راست‌چین (RTL) و مبتنی بر تقویم هجری شمسی (جلالی) پیاده‌سازی شده است.

---

## ۱. ویژگی‌ها و امکانات اصلی

- **پشتیبانی کامل از تقویم شمسی:** ورود و نمایش تمامی تاریخ‌ها به صورت شمسی و ذخیره‌سازی استاندارد میلادی در دیتابیس.
- **تبدیل هوشمند اعداد فارسی:** تبدیل خودکار کیبورد فارسی/عربی به اعداد استاندارد انگلیسی جهت جلوگیری از خطاهای دیتابیس.
- **پوشش کامل عملیات گله:**
  - **شناسنامه و مشخصات دام‌ها:** پلاک پلاستیکی، سریال، گوش فلزی، شناسه ملی، گونه (گوسفند/بز)، نژاد، شکم/تکرار بدن، منشأ، و خروج/حذف نرم.
  - **تولیدمثل:** ثبت سیدرگذاری، تلقیح مصنوعی/طبیعی، فحلی بدون تلقیح، دوره خشکی، و زایش (با باز شدن خودکار فرم ثبت بره/بزغاله تازه متولد شده).
  - **شجره‌نامه و همخونی:** محاسبه خودکار خلوص خونی و ضریب همخونی رایت (Wright's Inbreeding Coefficient $F$) و نمایش درخت شجره تا ۴ نسل.
  - **رکوردهای شیر و استانداردسازی:** رکوردگیری گروهی یا انفرادی شیر، اپلود اکسل، محاسبه شیر استاندارد بر اساس فواصل زمانی مجاز و رسم نمودار با Chart.js.
  - **عملیات جمعی:** فیلتر دام‌ها، تشکیل لیست کاری، و اجرای عملیات سریع یا بچ ترانزکشن با قابلیت رول‌بک در صورت خطا.
  - **بانک اسپرم و انبار دارو:** مدیریت موجودی انبار، تراکنش‌های ورود و خروج، و کنترل لحظه‌ای موجودی.
  - **بهاربندها و ترکیب گله:** جابجایی دام‌ها و آمار لحظه‌ای ساختار گله (ماده، نر، بره، آبستن، شیروار).
  - **گزارش‌گیری و خروجی:** خروجی اکسل (`.xlsx`) و فایل PDF برای تمامی گزارش‌ها و کارت هویت دام.

## ۲. پیش‌نیازها و راه‌اندازی سریع

### نصب پیش‌نیازها
مطمئن شوید پایتون (نسخه ۳.۱۱ یا بالاتر) روی سیستم نصب است. سپس دستورات زیر را اجرا کنید:

```bash
# ایجاد محیط مجازی
python -m venv venv

# فعال‌سازی محیط مجازی
# در لینوکس/مک:
source venv/bin/activate
# در ویندوز:
# venv\Scripts\activate

# نصب پکیج‌های مورد نیاز
pip install -r requirements.txt
```

### اجرای برنامه

```bash
python run.py
```

پس از اجرای این دستور:
1. دیتابیس SQLite در مسیر `instance/farm.db` به طور خودکار ایجاد می‌شود.
2. دمو دیتای اولیه (شامل ۴۰ دام، ۴ بهاربند، ۸ اسپرم، ۸ دارو، سوابق زایش و شیر) به صورت خودکار بارگذاری می‌گردد.
3. برنامه روی آدرس `http://127.0.0.1:5000` در دسترس خواهد بود.

## ۵. ساختار پروژه

```
livestock-manager/
├── run.py                       # نقطه ورود برنامه
├── seed_demo.py                 # اسکریپت بارگذاری داده‌های اولیه آزمایشی
├── requirements.txt
├── config.py
├── instance/                    # محل قرارگیری دیتابیس SQLite
├── app/
│   ├── models/                  # مدلهای SQLAlchemy دیتابیس
│   ├── routes/                  # بلوپرینت‌ها و مسیرهای URL
│   ├── services/                # سرویس‌های محاسباتی (تاریخ شمسی، شجره، شیر، PDF)
│   ├── forms/                   # فرم‌ها و ولیدیشن‌های WTForms
│   ├── templates/               # قالب‌های Jinja2 با ظاهر RTL
│   └── static/                  # فونت وزیرمتن، استایل‌ها و کتابخانه‌های JS
└── tests/                       # تست‌های خودکار pytest
```
